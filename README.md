# MPCC_Simulation_Videos_MEng
Simulation videos accompanying the Master's thesis: Trajectory Planning and Execution for a Quadrotor UAV with Swinging Payload, by Madeleine Ackermann, Stellenbosch University Electronic Engineering, 2026.

These videos serve as a demonstration of the load-aware and load-unaware MPCC control systems that were developed for 2-dimensional trajectory planning and control as part of the thesis.

The videos were created using MATLAB and Simulink's Simscape Multibody simulation environment. They show a quadrotor with a swinging payload traversing racetracks with the goal of obstacle avoidance and minimum-time trajectory execution. Only one lap of the racetracks is shown to limit file size.

Please refer to the images for a better illustration of track structure. The images show the trajectories of the systems over three laps.

NOTE: The obstacle just South of the starting point in Track 1 is hit when the quadrotor flies past it. However, as noted in the thesis, the system was only designed to avoid obstacles as it passes through the pairs of poles. Thus, this collision is not a failure of the system, but a limitation of the implementation.
